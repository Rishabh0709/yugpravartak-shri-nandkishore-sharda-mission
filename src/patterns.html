टेम्पलेट कैटलॉग

The shared building blocks every page composes from — tokens, text primitives, buttons, the section frame, and the recurring section shapes. Each block shows a live render and its markup. Build new pages (and the English site) from these; only add a scoped pages/*.css for genuinely new layout.

  • spacing scale: --sp-1…--sp-32 (4 / 8 based)

यह एक किकर है

{# ============ SECTION FRAME ============ #}

4 · Section frame

Every content section: <section class="hi-section …"> → <div class="hi-shell"> (max 1180px, auto-centred) → a hi-section-heading then content.

अनुभाग किकर

केंद्रित अनुभाग शीर्षक

वैकल्पिक standfirst पंक्ति जो शीर्षक के नीचे आती है।

markup
<section class="hi-section" aria-labelledby="x-title">
  <div class="hi-shell">
    <header class="hi-section-heading hi-section-heading--center">
      <span class="hi-kicker">…</span>
      <h2 id="x-title">…</h2>
      <p>…</p>
    </header>
    …
  </div>
</section>

Drop --center for a left-aligned heading. Alternate section backgrounds with background: var(--bg-wash).

{# ============ BREADCRUMB ============ #}

5 · Breadcrumb

Opt-in via front matter — partials/breadcrumb.njk renders it between header and hero. Trim ~40px off the hero's top padding.

मुख्य पृष्ठ/अभिभावक पृष्ठ/यह पृष्ठ
front matter
breadcrumb: true
breadcrumbName: "छोटा नाम"          # optional, else title before the "|"
breadcrumbParent: { "label": "अभिभावक", "href": "/parent.html" }   # optional middle crumb

5b · In-page section nav

Shared component in home-hindi.css. Use on overview / topic pages (about-mission, the chapter pages) where jumping between sections is useful — not on sequential biographies, which should be read in order. Static (not sticky), wraps instead of scrolling, label makes it read as an index. Keep scroll-margin-top on the target sections so the fixed header doesn't cover the heading.

इस पृष्ठ पर

उद्देश्य साधना पद्धति दिव्य आधार मानव सेवा निरंतरता
markup
<nav class="page-nav" aria-label="अनुभाग">
  <div class="hi-shell page-nav__links">
    <p class="page-nav__label">इस पृष्ठ पर</p>
    <a href="#section-id">अनुभाग</a>
    …
  </div>
</nav>

{# ============ PAGE RECIPE ============ #}

7 · A new page, start to finish

  1. Front matter: layout: base.njk, title ("नाम | मणिद्वीप अध्यात्म परिवार"), description, bodyClass: "hindi-home <slug>-page", breadcrumb: true (+ parent), extraCss: ["/assets/css/pages/<slug>.css"].
  2. Hero: <section class="<slug>-hero"> on --bg-wash — kicker, h1 (--step-h1, --primary), lead. Padding clamp(30px,4.5vw,52px) 0 … (the header placeholder already reserves 140px).
  3. Body: compose from §6 shapes inside hi-section + hi-shell; alternate --bg / --bg-wash.
  4. Close with a §6h band.
  5. Data that repeats or the English site needs → a src/_data/*.json file, not inline.
  6. Add JSON-LD only via head.njk front matter (person:, book:) or a page-scoped <script type="application/ld+json">.
  7. Every <img> carries real width/height.
  8. npx @11ty/eleventy → check the build, links, JSON-LD.
